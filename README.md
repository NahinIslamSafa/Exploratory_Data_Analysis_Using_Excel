# Exploratory_Data_Analysis_Using_Excel

This project analyzes bike sales data using Microsoft Excel, with a strong focus on Pivot Tables and dashboard visualization. The dataset was first cleaned and organized to ensure accurate analysis, after which customer attributes such as income level, age groups, gender, and commute distance were explored.

Pivot Tables were used to calculate key summaries such as average income by gender and purchase status, customer distribution across age brackets, and bike purchase behavior based on commute distance. These summaries helped identify meaningful patterns and comparisons within the data. The Pivot Table outputs were then converted into charts to make the analysis easier to understand.

An interactive Excel dashboard was created to present the insights in a clear and visual way. The dashboard includes charts showing average income per purchase, customer age brackets, and commute distance comparisons between customers who purchased bikes and those who did not. This dashboard allows users to quickly explore trends and draw conclusions from the data.

The main goal of this project is to strengthen practical Excel skills, particularly in data analysis, Pivot Table creation, and dashboard design. This project is intended for learning and practice
