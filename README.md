# Exploratory_Data_Analysis_Using_Excel

## Project Overview

This project focuses on exploratory data analysis (EDA) of bike sales data using Microsoft Excel, with an emphasis on data cleaning, Pivot Tables, and interactive dashboard development.

The dataset was cleaned and organized to ensure consistency and accuracy before conducting the analysis. Key customer attributes, including income, age group, gender, and commute distance, were examined to explore purchasing behavior and identify meaningful patterns in bike sales.

## Analysis and Methodology

Pivot Tables were used to summarize and analyze the data, focusing on the following aspects:

- Average income by gender and bike purchase status.
- Customer distribution across different age groups.
- Bike purchasing behavior in relation to commute distance.
- Comparisons between customers who purchased bikes and those who did not.

The resulting summaries were visualized through charts to make the findings easier to interpret and compare.

## Dashboard

An interactive Excel dashboard was developed to present the key findings in a clear and accessible format. It includes visualizations covering average income, customer age groups, and commute distance in relation to bike purchasing behavior.

The dashboard provides an overview of customer purchasing patterns and allows users to explore the data through interactive visual elements.
